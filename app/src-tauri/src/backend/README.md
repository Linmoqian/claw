# 后端模块

`servo.rs` 管理飞特 SDK 桥，`mcu.rs` 管理 MCU 串口，`debug_serial.rs` 管理单电机原始报文，`ai.rs` 管理模型桥。`common.rs` 只放跨模块错误转换与桥响应校验。新增 Tauri 命令在所属模块实现，并在 `lib.rs` 注册。

`experiments.rs` 将实验元信息、快照和采样分块写入应用数据目录。每次提交生成新清单；临时文件和未引用采样块不会参与读取，旧 IndexedDB 记录在前端首次读取时分批迁入且不删除原数据。

`assets.rs` 管理文档、视频和项目资产。文件经 512 KiB 前端分块传输，Rust 限制单块不超过 1 MiB，检查总长度后提交清单。`assets/catalog/` 在 SQLite 中分别索引模型、训练数据和文档元信息；列举时根据文件清单恢复索引。只有整类迁移成功才记录完成标记；失败时旧 IndexedDB 文件仍可重试。

`simulation/` 解析内置 URDF、维护唯一固定步长运行时并通过 Channel 输出有序状态；Rapier 负责场景道具物理。控制命令携带机型和递增序号，停止命令也参加序号校验，避免迟到的运动命令重新启动运动。桌面端消费 Rust 状态帧，浏览器预览继续使用前端仿真。

`drafts.rs` 原子保存积木工作区、旧数据摘要和工具档案。首次读取将旧浏览器原始字符串复制到桌面目录，不改动原 localStorage；损坏数据保持原样并阻止自动覆盖。

`replay.rs` 驱动桌面录像回放与插值。旧 `RecordingFile v1` 关节角仅在载入边界从角度换算为弧度；回放帧带递增序号和时间戳，退出时释放线程。浏览器预览仍使用原有回放桥。

`websocket.rs` 负责桌面端 WebSocket 建链、收发和断开，并用 Channel 向界面传递传输事件。连接尝试有 10 秒超时，主动断开会取消待连接会话；同一连接上的控制命令序号必须递增。页面层沿用既有协议和连接状态管理，浏览器预览仍使用浏览器 WebSocket。
