# 数字资产目录数据库

`schema.sql` 在桌面应用数据目录的 `assets/catalog.sqlite` 建立模型、训练数据、文档三张元信息表及迁移状态表。模型包含 3D 模型与模型权重，算法 ZIP 与视频沿用现有文件清单。大文件不写进 SQLite，仍由原子提交的清单和二进制文件保存。

首次列举将旧清单迁入 SQLite，此后模型、训练数据和文档的增删查由 Rust 操作数据库。写入文件前先保存恢复标记；若文件提交后数据库写入失败或应用异常退出，下次列举才从清单重建对应表。旧清单保留作为大文件定位与恢复依据。数据库版本通过 `PRAGMA user_version` 检查，较新版本拒绝被旧应用打开。
