# 对外设备接口

`index.ts` 是五类设备的公共入口：电机、无人机、机械臂、舵机、激光雷达。类别按物理对象划分，TTL、RS485、CAN 是适配器的通信方式。数值在接口边界使用 SI 单位，时间戳使用 Unix 毫秒。

`DeviceRegistry` 只收纳已实例化的适配器；未接入驱动的类别不会自动出现。适配器在创建时持有 TTL、RS485、CAN 或网络连接配置，调用 `connect` 和 `disconnect` 管理会话。可选方法缺失表示设备不支持该能力，调用方应据此禁用操作并说明原因。`stop` 只表示停止当前运动指令，不代替硬件急停。具体协议、控制互斥与安全校验仍由 Rust 后端和已有设备会话执行，不能仅依赖前端接口类型。
