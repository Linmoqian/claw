# 应用状态

Zustand stores 保存跨页面的工作台状态。

- `aiSessionStore.ts`：AI 会话、配置、草稿、消息与请求动作；纯内存，不保存密钥或本地路径到磁盘。页面卸载不会停止请求或重复初始化配置。
- `trainingSessionStore.ts`：离线训练参数、结果、提示和结果生成时的机型上下文；纯内存，结果的数据来源明确为内置合成数据。
- `activity.ts`：实验录制、回放与设备占用的全局互斥标志，供 stores、渲染层与各功能域读写。
- 其他 store 分别维护机器人、场景、仿真、交互和设备桥接状态。

这些模块不需要独立环境变量或生成产物目录；全局忽略规则继续生效。
